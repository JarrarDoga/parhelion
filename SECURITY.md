# Security Policy

## Supported versions

Parhelion is pre-release software. Security fixes go to the `main` branch and to the latest
release, once releases exist.

## Reporting a vulnerability

Do not open a public issue for a security problem.

Report it privately through GitHub:
[Report a vulnerability](https://github.com/JarrarDoga/parhelion/security/advisories/new).
Include a description of the problem, the steps to reproduce it, and the affected versions or
commits.

You can expect an acknowledgement within 7 days. We will keep you informed while we work on a
fix, and we will credit you in the advisory unless you ask us not to.
